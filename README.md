## 📦 Featured Project

### 🇳🇵 [Nepāli Miti — नेपाली मिति](https://github.com/PRADIPGOSAIN/nepali-miti)

> A clean, fast, **ad-free** Nepali calendar — the Hamro Patro alternative without the bloat.

| Feature | Description |
|---|---|
| 📅 **BS Calendar & Festivals** | Full Nepali calendar with festivals & holidays |
| 🔄 **BS ⇄ AD Converter** | Two-way date conversion, today's date in Nepali |
| 🔮 **Rashifal** | Daily horoscope with lucky numbers |
| 📈 **Live NEPSE** | Real-time stock market data |
| 💱 **Forex & Rates** | Currency exchange with change tracking |
| 🥇 **Gold / Silver** | Live precious metal rates |
| 📰 **News Reader** | Popup-free Nepali news |

**Stack:** Next.js 16 · TypeScript · Tailwind v4 · Zustand · Prisma · React Query

▶ **Live:** https://nepali-miti-b27g9m40x-pradips-projects-ec7f3e20.vercel.app/
